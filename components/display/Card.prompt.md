Content card with optional gradient icon tile — service cards, quality principles, machine frames.

```jsx
<Card icon={<CogIcon />} title="Precision Machining" hover>
  Havacılık parçaları için yüksek hassasiyetli işleme hizmetleri.
</Card>
<Card variant="framed" title="HAAS UMC750">…</Card>
```

Variants: `default` · `framed` (2px orange frame + orange glow, for machines/offers) · `inverse` (dark steel). Add `hover` for the 6px lift.
