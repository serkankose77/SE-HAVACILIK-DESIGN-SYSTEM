Recurring section opener: mono kicker + Saira title + 64×3 orange rule + optional lead.

```jsx
<SectionHeading center kicker="Hizmetlerimiz" title="Comprehensive Machining Solutions"
  sub="Havacılık endüstrisi için kapsamlı hassas işleme çözümleri sunuyoruz." />
```

Use `center` for section openers, left-aligned for split layouts; `onDark` on steel sections.
